# Weather App Project

This weather app project is an app where users can track the weathers of certain cities, and add as many tags as they wish to each city

Relations as follow: 
    - User can have track many cities (WeatherProfiles), a profile belongs to one user
    - User can have many Tags, a tag may belong to one user
    - Tags can have many Weather Profiles, and a Weather profile may have one or more tags
